# UI and UX Principles

- Make “Identify a record” the unmistakable primary action.
- Keep the golden path on one workspace when possible. Avoid redundant confirmation pages.
- Use near-black, warm cream, restrained oxblood, brass, and moss. Let artwork and spacing carry hierarchy; avoid a grid of bordered dashboard cards.
- Pair editorial display typography with a direct sans-serif UI face.
- Show edition-defining fields together: country, date, label, catalogue number, format, barcode, and identifiers.
- Confidence labels describe workflow guidance, never statistical probability. Make their reasons inspectable.
- Provide loading, empty, error, partial, and success states for every data view.
- Preserve entered evidence through failures.
- Make mobile controls reachable and layouts useful from 320 px upward.
- Ensure keyboard operation, visible focus, semantic HTML, WCAG 2.2 AA contrast, live status announcements, and reduced-motion support.
- Use restrained transitions only when they clarify spatial or state change.
- Never use decorative charts when the collection has insufficient data.
